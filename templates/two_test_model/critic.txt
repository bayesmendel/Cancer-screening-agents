=== MODEL CONTEXT (DO NOT IGNORE) ===

Assume the following natural history model:

S0 → Sp1 → Sp2 → Sc

- S0 = disease-free or preclinical disease not yet detectable by Test 1
- Sp1 = preclinical, asymptomatic cancer detectable by Test 1 only
- Sp2 = preclinical, asymptomatic cancer detectable by both Test 1 and Test 2
- Sc = clinical (symptomatic) cancer

The key structural assumption is MONOTONIC DETECTABILITY:

For each cancer represented by this pathway, there must be a plausible preclinical period in which that same cancer is detectable by Test 1 but not Test 2 (Sp1), followed by a later preclinical period in which it is detectable by both tests (Sp2), before symptomatic presentation (Sc). Thus, if Test 2 detects an asymptomatic cancer, Test 1 would also detect that same cancer, and Test 1 must plausibly become capable of detecting it earlier.

This is a within-cancer temporal-progression constraint, not merely static or population-level inclusion of Test 2’s detectable set within Test 1’s. A difference based only on fixed anatomical coverage, cancer location, or another feature that makes some cancers detectable by Test 1 but never by Test 2 does not establish the required Sp1 → Sp2 transition. Likewise, simultaneous onset of detectability by both tests does not establish a genuine Sp1 period. Direct comparative or longitudinal evidence is preferred when available; otherwise, a transparent clinical, biological, or technical rationale may support this relationship as an explicitly stated modeling assumption, with its limitations described. Calling it a modeling assumption does not by itself make a pair structurally compatible.

This does not require Test 1 to have higher reported sensitivity than Test 2 within the same state, to start earlier, stop later, or occur more frequently. Test numbering represents model roles, not chronological schedule order. Ordinary false-negative results or imperfect sensitivity do not by themselves violate the ordering; the issue is whether the same cancer can plausibly enter both test-defined detectable states in the required sequence.
